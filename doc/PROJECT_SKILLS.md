# Project Skills

This repository now includes project-local Codex skills under `.codex/skills/`.

## Available Skills

| Skill | Purpose |
|------|---------|
| `manuscript-review-triage` | Turn reviews and critiques into tracker-ready comment sets, statuses, and revision plans |
| `sem-manuscript-audit` | Audit SEM manuscripts for reporting, design, timing, and interpretation problems |
| `data-provenance-appendix` | Draft and audit appendix text for sources, linkage, harmonization, and data availability |
| `docx-quarto-manuscript-bridge` | Convert manuscript structure between DOCX and Quarto, or reapply supplied Word-manuscript formatting to rendered DOCX outputs |
