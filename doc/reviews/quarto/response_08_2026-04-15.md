## Major Comments

### Comment 1: Decision rule too ad hoc; Class I conflates measurement with sample-scope

**Status**: VALID — RESOLVED

The §4.1 "Decision Rule, Estimand Taxonomy, and 'Benchmark-Ready'" subsection is substantially revised. The 5/6 sign and 4/6 magnitude cutoffs are now explicitly framed as a *heuristic reporting convention*, not a statistical decision test, in the spirit of specification-curve [@simonsohn2020] and multiverse [@steegen2016] analyses (both newly added to the bibliography). Researchers preferring different cutoffs can apply their own rule to the same audit output.

Class I has been split into Class Ia (measurement-preserving perturbations within the same estimand and population) and Class Ib (sample-scope perturbations — same construct, different population). The decision rule applies to Ia and Ib jointly, with the explicit caveat that Ib failures can reflect population heterogeneity rather than pure measurement instability. @tbl-robustness-summary and @tbl-sensitivity (Appendix C.1) are relabeled accordingly. The full classification:

- Class Ia: state-clustered bootstrap, weak-indicator drop, residualized burden, maturity-band controls, portfolio-scale controls
- Class Ib: local-only, nonzero-QCEW, local-only-AND-nonzero-QCEW, mature-only, NDR/Mitigation-excluded
- Class II: raw-counts bridge (clean), financial-ratio bridge (flagged II* for construct reassignment)
- Class III: SEM vs Cox

### Comment 2: SEM too fragile to anchor audit

**Status**: PARTIAL — STRENGTHENED FRAMING

We retain the reference-SEM framing (not "primary") established in R6. The observed-variable OLS analogue (§5.4 Audit Item 3 subsection, and @tbl-observed-main) is elaborated with the finding that the SEM's Burden→Timeliness coefficient ($\beta_{\text{SEM}} = +0.266$) is nearly identical to the observed-composite coefficient ($b = +0.276$), indicating the SEM functions primarily as dimension reduction. Full replacement of the SEM by the observed-composite as the primary specification is flagged as future work per user scope decision.

### Comment 3: Narrow QCEW framing; separate proxy fragility from construct reassignment

**Status**: VALID — RESOLVED

Abstract, EfP, §6.1, and Conclusion normative language now references "NAICS 925110-based capacity measurement" or "heavily suppressed sectoral staffing proxies" rather than "administrative capacity in general." The substantive scope is explicitly narrowed: the audit demonstrates NAICS-925110-based measurement is fragile in CDBG-DR, especially for locals; whether findings built on more direct staffing data (jurisdiction surveys, OPM-style records) would pass the audit is an open question.

@tbl-robustness-summary and the §5.4 prose separate the raw-portfolio-counts bridge (Class II, clean operationalization change, $\beta = -0.443$) from the financial-ratio bridge (Class II*, operationalization change + construct reassignment, $\beta = -0.600$). The financial-ratio bridge result is explicitly presented as less informative than the raw-counts result because part of the $-0.600$ reflects the outcome-to-predictor shift, not pure measurement-sensitivity.

### Comment 4: Sample construction opaque; consider local-only as main analysis

**Status**: VALID — RESOLVED

A new linker script (`scripts/rebuild_upstream_sample_flow.py`) reconstructs the upstream F31 → administering-jurisdiction pipeline and produces exact per-stage counts:

- 3,147 distinct Activity Responsible Org labels in raw F31
- 34 state-agency grantees (30 survive complete-case SEM deletion)
- 318 direct Census county-name matches
- 677 city-of-type labels requiring crosswalk
- 444 institutional/non-geographic labels
- 1,708 unresolved by automated rules
- 577 aggregated upstream → 573 surviving SEM sample

Appendix A.5's @tbl-upstream-geo now reports these exact counts and explicitly acknowledges that full reproduction of the original Kaifa pipeline's manual-adjudication step requires the raw F31 plus Census reference data (not artifacts preserved in the repository).

Local-only (N = 543) is promoted to equal-billing in @tbl-structural: both pooled (N = 573) and local-only coefficients are reported for all main structural paths. Substantive conclusions match closely ($\beta = +0.257$ local vs $+0.266$ pooled for capacity-timeliness; $-0.170$ for AdminResources-performance in both). Local-only fit is slightly worse (CFI 0.902 vs 0.915); the audit verdict holds on both samples. Full restructure around local-only primacy is flagged as future work per user scope decision.

### Comment 5: Cross-framework overinterpreted; within-Cox divergence to main text

**Status**: VALID — RESOLVED

§5.5 now has a dedicated paragraph on within-Cox divergence: the time-varying Cox returns null hazard ratios (HR ≈ 1.0, p ≈ 0.99), while the complementary single-spell Cox at the same thresholds returns HR = 1.46 at 20% rising to HR = 2.58 at 100% (p < 0.01 throughout). This within-framework measurement sensitivity is presented as parallel to the within-SEM Class II bridge reversals. The cross-framework conclusion is explicitly narrowed: "analytically reasonable designs yield different answers on the same data, and the within-Cox instability means some of what looks like framework-level divergence is actually within-framework measurement sensitivity."

### Comment 6: Methods vs empirical identity

**Status**: PARTIAL — methods-forward framing retained

The Introduction §1 restatement of the 0.266 verdict has been removed; the Abstract, EfP, §5.4, and §6.1 now carry the substantive verdict. The protocol is clearly the lead contribution in abstract, introduction, and conclusion; the empirical demonstration remains bounded to CDBG-DR. No structural restructure.

### Comment 7: AdminResources "benchmark-ready" internal contradiction; EfP tone-down

**Status**: VALID — RESOLVED

§6.1 now explicitly distinguishes a *statistical-stability* verdict (benchmark-ready = stable associational estimate across the measurement and sample-scope perturbations the audit exercises) from a *policy-ready* verdict (requires additional causal identification argument). AdminResources → RecoveryPerformance passes the statistical-stability verdict; the portfolio-complexity caveat means it does not pass the policy-ready bar without a portfolio-complexity instrument or measurement. The protocol's rubric flags what to trust statistically; separate identification argument is what turns a stable association into a policy anchor.

The EfP is reordered: the six audit items precede the benchmark-ready sentence, which now explicitly names the statistical-stability-vs-policy-ready distinction. Policy implications close the EfP with an explicit causal-caveat clause.
