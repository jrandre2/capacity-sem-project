# Kaifa Redesign Decision Memo

**Date**: 2026-04-09

## Recommended Path

Use the Kaifa package as an archival, exploratory SEM manuscript rather than
as a publication-ready confirmatory paper.

## Why

- the strong positive legacy SEM result depends on right-censored duration
  plus inverse-duration timeliness;
- non-circular SEM specifications are not statistically persuasive;
- the state/local subset samples are too small for strong comparative
  claims;
- the later Word draft's external-data additions are not fully reproducible
  in the current archive.

## Paths Forward

### Path 1: Exploratory archival manuscript

This is the path implemented in the current turn.

- keep the paper cross-sectional and explicitly exploratory;
- use descriptive QPR evidence plus audited model-comparison tables;
- remove unsupported moderation, causal, and risk-index claims;
- preserve the archive as a transparent lineage record.

### Path 2: Rebuild the expanded cross-sectional manuscript

Only pursue this if the project wants to keep the later Word draft's broader
construct story.

Required work:

- reconstruct QCEW joins with suppression and missingness documentation;
- harmonize or restrict SVI vintages;
- validate geography matching against official Census files;
- rerun all tables and figures from source scripts rather than from inherited
  prose.

### Path 3: Port the substantive question into the active survival workflow

This is the strongest causal-timing path in the repository, but it is no
longer an SEM paper.

- use the standardized panel and proper censoring logic;
- treat the Kaifa SEM manuscript as historical lineage only;
- rebuild the substantive narrative around time-varying or event-history
  results instead of cross-sectional latent-variable estimates.

## Practical Rule

Do not add new claims to the Kaifa manuscript unless they can be tied to a
reproducible table or figure already present in the repository.
