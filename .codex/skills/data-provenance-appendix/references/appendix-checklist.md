# Data Provenance Checklist

## Mandatory Sections

- Raw data sources
- Version or vintage information
- Geography and unit of observation
- Matching and crosswalk logic
- Filters and exclusions
- Derived variables and thresholds
- Public versus restricted materials
- Replication or code-availability statement

## Source Questions

For each source, answer:

- What agency produced it?
- What exact release or vintage is used?
- What time span does it cover?
- What geography does it represent?
- What caveats affect comparability or completeness?

## This Repo's Recurring Risks

- QPR timing measures can encode maturity bias and censoring.
- QCEW is an indirect staffing proxy and may include suppression or comparability issues.
- SVI releases are not automatically comparable across time.
- Geography matching needs explicit validation and source hierarchy.

## Data Availability Pattern

Use wording that separates:

- publicly available source datasets
- restricted or manual linkage artifacts
- code and formulas that can still be shared
